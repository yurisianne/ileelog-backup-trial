일이로그 체험판

Roll20, 코코포리아 로그를 티스토리에 붙여넣을 HTML로 바꿔줘요. 로그 내용은 서버로 보내지지 않고 이 브라우저 안에서만 처리돼요. 작업 내용은 이 기기의 브라우저에 저장돼서 새로고침해도 남아 있어요.

1. 로그 붙여넣기

Roll20 로그를 드래그해서 복사(Ctrl/Cmd+C)한 뒤, 아래 칸에 붙여넣어 주세요(Ctrl/Cmd+V). 색상과 이미지 서식은 그대로 유지돼요.

2. 변환

내 대사(파란 배경)는 회색으로 통일하고, 주사위 팝업은 화면 크기에 맞게 바꿔요. 귓속말은 원래 색을 그대로 둬요.

3. 첨부 사진 크기 조절 (있는 경우)

슬라이더나 숫자로 0~200% 사이 크기를 정하면 결과에 바로 반영돼요.

4. 결과

1. 로그 파일 업로드 및 순서 지정

코코포리아에서 내보낸 로그 .html 파일을 올려주세요. 여러 개를 올리면 드래그(또는 ▲▼)로 합칠 순서를 정할 수 있어요. .zip 파일도 올릴 수 있고, 안에 든 HTML 로그를 자동으로 풀어줘요. 같은 탭을 여러 번 내보내 겹치는 부분은 자동으로 합쳐요.

2. 탭 구성

탭마다 어디에 보여줄지 골라주세요. 정보 탭은 나온 시점에 고정 상자로 들어가고, 나머지는 기본적으로 메인에 들어가요. 잡담(other)·비밀 탭은 기본으로 빠져 있어요. 접이식 상자로 따로 빼려면 "기타"로 바꿔주세요.

탭 이름줄 수이 탭을 어떻게 백업할까요?

3. 캐릭터 아이콘 · 이름 색상 · 나레이션 역할 (선택)

HTML 로그의 표정 이미지가 있으면 자동으로 아이콘에 써요. '표정 조정'에서 드래그로 위치를, 휠이나 슬라이더로 크기를 바꿀 수 있어요. 이름 색은 동그란 버튼으로 바꿔요. '-' 대신 다른 이름으로 나레이션을 하는 경우, 그 이름을 "내레이션" 또는 "서브 나레이션"으로 지정하면 연출 문장이 각각 다른 스타일로 나와요.

나레이션 역할 일괄 지정
인장 모양 (전체 적용)

4. 첨부 사진 크기 조절 (있는 경우)

대사 안에 붙여넣은 사진(스탠딩 등)을 하나씩 키우거나 줄일 수 있어요. 슬라이더나 숫자로 0~200% 사이 크기를 정하면 결과에 바로 반영돼요.

1. JSON 로그 파일 업로드

코코포리아 방에서 내보낸 로그 JSON 파일을 올려주세요. 대사마다 그 순간의 표정(스탠딩) 이미지가 함께 나와요. 여러 개를 올리면 시간순으로 합치고, 겹치는 메시지는 자동으로 지워요.

2. 탭 구성

탭마다 어디에 보여줄지 골라주세요. 정보 탭은 나온 시점에 고정 상자로 들어가고, 나머지는 기본적으로 메인에 들어가요. 잡담(other)·비밀 탭은 기본으로 빠져 있어요. 접이식 상자로 따로 빼려면 "기타"로 바꿔주세요.

탭 이름줄 수이 탭을 어떻게 백업할까요?

3. 캐릭터 이름 색상 · 나레이션 역할 (선택)

이름 색은 바꿀 수 있어요. '-' 대신 다른 이름으로 나레이션을 한 경우에는 그 이름에 "내레이션"을 체크해 주세요.

나레이션 역할 일괄 지정
인장 모양 (전체 적용)

4. 표정 이미지 표시 위치 (선택)

표정 이미지마다 보여줄 부분을 따로 정할 수 있어요. 3×3 버튼으로 위·가운데·아래, 왼쪽·가운데·오른쪽 위치를 골라주세요. 기본값은 위쪽 가운데예요. 미리보기는 실제 아이콘 영역(56×72px) 기준이에요.

5. 생성

프리셋을 고른 뒤 색을 직접 바꾸면 '커스텀'으로 바뀌어요. 배경색과 나레이션 색을 따로 정할 수 있어요.
